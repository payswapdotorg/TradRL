# TradRL Adapter Boundary

External systems are substrates. Canonical domain contracts remain provider-neutral.

## Market data
Categories: crypto exchanges, equities/index, futures, options, macro, news, social and alternative data.
Reference examples: Binance, Coinbase and licensed S&P/index data.
Adapters preserve provenance and entitlement constraints.

## Execution
Broker, exchange-native API, paper venue and OMS/EMS integrations. Every consequential order passes through internal execution authority/risk gates.

## Models
Translate provider/model APIs into CognitiveSubstrate. A model provider never owns an Agent Body.

## Human expertise
Arena is one optional capability provider. Supported operations: request, expert evidence, demonstration, annotation, evaluation and capability artifact.

## Licensing
Commercially licensed data remains access-controlled and is not copied into artifacts contrary to provider terms.
