# TradRL Capability and Substrate Discovery

TradRL must discover missing capabilities, synthesize useful specializations, search available Agent Bodies and Cognitive Substrates, and empirically test candidate possessions. No human must predefine every role/model pairing.

## Discovery loop
1. Detect capability deficit from task/project evidence.
2. Characterize the required capability contract.
3. Generate candidate specialization/role descriptions.
4. Search reusable Skills and Agent Bodies.
5. Search candidate Cognitive Substrates from the model registry.
6. Benchmark candidates on task-specific capability suites.
7. Check tool, context, latency, cost and runtime compatibility.
8. Instantiate candidate Possessions.
9. Evaluate candidate organizations in the Market World.
10. Retain candidates only when they improve objective satisfaction under constraints.

## Example
A project may repeatedly fail because its strategies require difficult mathematical optimization or stochastic-process analysis. TradRL can infer a Mathematical Researcher specialization, find suitable existing bodies/skills or create a new body specification, then test available models.

A specialized mathematics model such as Limite can therefore become a candidate substrate based on measured capability rather than a hard-coded rule.

## Never equate model and profession
`model -> measured mathematical reasoning capability -> candidate possession` is valid.
`model -> mathematician` is not an evidence-backed architectural rule.

## Discovery levels
- Reuse an existing Body and substrate.
- Recompose existing Skills/Bodies.
- Create a new Body specification.
- Autonomously train/improve.
- Optionally request human expertise through the capability-provider interface.

## Safety
Discovery does not grant consequential execution authority. Risk, authorization and execution policy remain independent gates.

## Reproducibility
Record candidate roles, bodies, models, benchmarks, datasets, configuration, cost, latency, environment, outcomes and rejected candidates.
