# TradRL Learning Loop

## Native loop
Goal -> organization hypothesis -> body selection/creation -> environment compilation -> training -> trajectory -> evaluation -> verification -> failure analysis -> skill extraction -> Body Version -> compatibility -> shadow -> outcome -> next experiment.

## Organization learning
Search over agent count, specializations, bodies, models, communication topology, training allocation, decision cadence and adversarial population.

## Curriculum
1. Simple synthetic regimes
2. Historical replay
3. Microstructure and friction
4. Reactive market
5. Adversarial population
6. Unseen multi-regime tests
7. Rolling Time Machine
8. Shadow trading
9. Controlled live execution when permitted

## Failure-driven learning
Failures create typed CapabilityGaps such as regime, sentiment/event, liquidity, execution, risk or coordination failure.

## Method selection
Per capability: RL, offline RL, supervised learning, imitation, preference optimization, bandits, self-play, adversarial training, population search or statistical/causal methods.

## Human augmentation
Persistent gap -> optional expertise request -> Arena/expert -> artifact -> local import -> local evaluation -> next learning experiment.
Arena is not in the critical native learning loop.
