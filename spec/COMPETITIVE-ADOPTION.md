# Competitive Adoption

## Primary adoption metric
Main-interface adoption is the first objective. Exclusive replacement is a later outcome.

## Adoption ladder
Connected tool -> frequently used tool -> primary workflow -> main interface -> system of record -> infrastructure replacement where justified.

## Retention mechanisms
Project-centric workflow; deep incumbent integrations; Firm Brain; watchable organizations; evidence/provenance; Time Machine; adversarial/risk evaluation; native execution; continuous learning from project outcomes.

## Strategy
Do not compete only on having agents. The differentiator is continuity: Question -> organization -> research -> point-in-time world -> simulation -> testing -> decision -> execution -> outcome -> institutional learning.

## Enterprise
Users may keep Bloomberg/LSEG/FactSet/TradingView/QuantConnect/TT/IBKR/internal systems underneath TradRL. Orchestrate first; replace only where earned.
